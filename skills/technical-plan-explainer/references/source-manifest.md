# 维护来源与覆盖

模式 hybrid；覆盖 partial。W/U/E/A 是来源分级。

- W：可追溯的 Skill 世界观、应用与能力分层、跨 Agent 隐私与按需检索方法，已综合为控制边界与本地路线。运行不依赖源知识库。
- U：技术方案要通过可见机制动画解释；采用 HyperFrames、固定且已接受的 Cove 母版、离线 HTML 与可暂停跳转的观看体验。
- E：[HyperFrames 官方源码](https://github.com/heygen-com/hyperframes)，0.8.168 的核心编译器、原生播放器、GSAP 注册、媒体定位、lint/check/keyframes；当前 seedaudiocli 0.2.1 的 audio-ref、任务恢复和字幕输出。首次实施验证了单段中文与离线播放；通过的样片与接受记录留在开发目录，普通运行不读取。
- A：将状态问题映射为机制原语、按语义分段与章节长度的判断，是应用方法；新题材仍以实际阅读效果和事实验收验证。

覆盖缺口：其他 Agent/操作系统、长篇多段连续听感、扫描件读取与各种方案的迁移质量需分别验证。完整稿长度受用户目标决定；源数据不足时明确缺口。新样本显示表达失败、声音合同或 HyperFrames 主要 API 变化时重新编译相关知识或适配；业务策略变化不改写底层能力插件。开发回归材料独立保存，用户明确要求后才运行干净上下文评测。
